Post-publication corrections

Corrections identified after publication of “Spatial frequency loss for mitigating spectral bias in deep neural networks.”

Status. This is an author-maintained correction record. A formal correction request to the publisher is planned. When a publisher-issued correction becomes available, its permanent link will be added here.

1. Table 2, ℒB row

The published ℒB row contains subband-loss values from the seed-20 baseline run. The formally selected baseline run was seed 10, selected because it had the smallest final pixel-wise L2 loss among seeds 10, 20, and 30. Supplementary Table S9 records final PL2L values of 2.713, 2.931, and 3.009 × 10−3, respectively.

The published row is:

ℒB, published (seed 20)17.3723.7726.6817.007.5244.78217.89

The corrected row, using the formally selected seed-10 run, is:

ConditionSB1SB2SB3SB4SB5SB6SB7
ℒB, corrected (seed 10)17.1722.8423.0612.406.7475.16724.36

The correction changes only the numerical values in the Table 2 ℒB row. It does not change the caption, main text, conclusions, or the reported effect of SFL.
