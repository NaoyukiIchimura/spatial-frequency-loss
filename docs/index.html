Spatial Frequency Loss

A subband-aware loss designed to mitigate spectral bias in deep neural networks and improve the reconstruction of fine image details.

View the public repositoryRead the paper

Overview

Deep neural networks trained with pixel-wise losses can reduce low-frequency errors more rapidly than high-frequency errors. Spatial Frequency Loss (SFL) complements the pixel-wise reconstruction loss by measuring discrepancies between corresponding frequency-selective responses of output and target images.

Frequency-selective measurements

A difference-of-Gaussians filter bank provides overlapping subband responses. The subband losses are frequency-selective measurements, not an orthogonal or energy-preserving decomposition.

Data-driven weighting

Inverse Error Ratio weighting increases the influence of bands whose observed errors are relatively small, without assuming a fixed image spectrum.

Minimal integration

The public implementation is a regular PyTorch module. Existing models, data loaders, optimizers, and training loops need only localized additions.

Public software

The public package supports fixed and calibration IER modes. Dynamic weight control is outside the public scope. The default filtering backend is separable; conv2d remains available for compatibility and numerical verification.

from spatial_frequency_loss import SpatialFrequencyLoss

sfl = SpatialFrequencyLoss(
    ier_update_mode="calibration",
).to(device)

subband_losses, weighted_sfl, _, _, active_weights = sfl(outputs, targets)
total_loss = reconstruction_loss + quantizer_loss + weighted_sfl
Checkpoint behavior. IER weights and calibration state are persistent buffers in state_dict(). The filtering backend is a construction-time configuration and should match the intended checkpoint configuration.

Computation time

The paper measured FFHQ training with 40,000 images resized to 256 × 256, batch size 4, and three complete epochs of 10,000 iterations each. The interval included GPU transfer, forward propagation, loss computation, backward propagation, and the optimizer update.

The first four rows are from Table 6 of the paper. The separable backend was implemented after publication and was therefore unavailable for the original evaluation. A post-publication measurement under the same measurement procedure found an approximately 4.01-fold speed-up over the original SFL implementation and an approximately 75.05% reduction in SFL training time. Both backends implement the same mathematical filtering operation.
